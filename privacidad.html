Política de privacidad

Última actualización: 1 de septiembre de 2026.

Esta política describe de forma general cómo Nutri Consultas maneja información cuando se utiliza la aplicación de escritorio y sus integraciones opcionales.

1. Datos almacenados

Nutri Consultas puede almacenar localmente información ingresada por el usuario para gestionar pacientes, consultas, mediciones, planes nutricionales, agenda, configuración y documentos generados.

2. Servicios de terceros

Algunas funciones pueden conectarse opcionalmente con Google o Microsoft para correo electrónico, almacenamiento o respaldo. Estas conexiones requieren autorización explícita del usuario mediante mecanismos oficiales del proveedor.

3. Credenciales

Nutri Consultas no requiere que el usuario entregue directamente su contraseña de Google o Microsoft al desarrollador. Las integraciones se realizarán mediante OAuth u otros mecanismos oficiales.

4. Respaldos

Los respaldos hacia servicios compatibles se guardan en la cuenta autorizada por el usuario. La creación y restauración se realizan bajo decisión del usuario.

5. Uso de la información

La información se utiliza para las funciones propias de la aplicación. No se vende información personal del usuario ni de sus pacientes.

6. Seguridad

Se aplican medidas técnicas razonables; el usuario también es responsable de proteger su computadora, credenciales, cuentas y copias de respaldo.

7. Cambios

Esta política puede actualizarse para reflejar cambios técnicos, funcionales o regulatorios.

8. Contacto

Para consultas use la página de Soporte.
